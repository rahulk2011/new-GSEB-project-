# ⚙️ Setup & Local Execution Guide
**Project:** EduBharat AI
**Architecture:** Zero-Dependency Single-Page Application (SPA)

## 1. Overview
EduBharat AI v1.0 is engineered with a zero-dependency architecture. It requires no Node.js runtime, external package managers (npm/yarn), or complex compilation pipelines. It runs instantly inside any modern web browser.

## 2. Prerequisites
* Any standard modern web browser (Google Chrome, Brave, Safari, or Mozilla Firefox).
* Mobile environment: Android (version 9.0+) or iOS (version 14.0+).

## 3. Running Locally on Mobile (Android)

### Method 1: Mobile Code Editors (Recommended)
1. Open your mobile code editor of choice (**TrebEdit**, **Acode**, or **Spck Editor**).
2. Create or clone the repository into your local storage.
3. Open `index.html`.
4. Tap the in-app **Play / Preview** button to launch the live application in the embedded webview.

### Method 2: Termux (Local HTTP Server)
For developers using command-line environments like Termux:
```bash
# Navigate to project directory
cd EduBharat-MVP

# Start a lightweight Python HTTP server
python -m http.server 8080
```
Open your mobile browser and navigate to: `http://localhost:8080`

## 4. Running Locally on Desktop
1. Clone the repository:
   ```bash
   git clone [https://github.com/rahulk2011/EduBharat-MVP.git](https://github.com/rahulk2011/EduBharat-MVP.git)
   ```
2. Navigate to the project root directory.
3. Double-click `index.html` to open it directly in your browser.
4. Open Chrome Developer Tools (`F12`), toggle the device toolbar (`Ctrl + Shift + M`), and select **Mobile View** for the intended responsive experience.

## 5. Live Cloud Deployment via GitHub Pages
1. Navigate to your GitHub repository: `https://github.com/rahulk2011/EduBharat-MVP`.
2. Go to **Settings** > **Pages** (under the "Code and automation" section).
3. Under **Branch**, select `main` from the dropdown and leave the folder set to `/(root)`.
4. Click **Save**.
5. Within 1 to 2 minutes, GitHub will provide a live deployment URL (e.g., `https://rahulk2011.github.io/EduBharat-MVP/`) accessible for classroom and stakeholder demonstrations.
