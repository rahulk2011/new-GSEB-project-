# 🎨 Design System & UI Architecture
**Theme:** Premium Dark Mode (Mobile-First)

## 1. Design Philosophy
The UI is strictly engineered for low-end mobile devices and utilizes a high-contrast **Premium Dark Mode** to reduce eye strain (accessible for low-vision users) and preserve battery life.

## 2. Color Tokens (CSS Variables)
Strict adherence to the following Hex codes:
* `--bg-base`: `#0f172a` (Slate 900) - Main Background
* `--bg-surface`: `#1e293b` (Slate 800) - Cards and Containers
* `--primary-accent`: `#6366f1` (Indigo 500) - Primary Buttons
* `--secondary-accent`: `#10b981` (Emerald 500) - Success/Progress
* `--danger-accent`: `#ef4444` (Red 500) - Errors/Absent status
* `--text-main`: `#f8fafc` (Slate 50) - Headings & Body
* `--text-muted`: `#94a3b8` (Slate 400) - Subtitles

## 3. Typography
* **Font Stack:** `system-ui, -apple-system, sans-serif` (Zero external HTTP requests).
* **Base Size:** `16px` for optimal mobile readability.

## 4. Layout & Grid
* **Structure:** Pure CSS Flexbox and CSS Grid. NO HTML `<table>` tags.
* **Container:** Maximum width constrained to `768px` to simulate a native app feel on desktop browsers.
* **Spacing:** Base padding/margin of `16px` (1rem).

## 5. Components
* **Buttons:** 8px border-radius, `transition: all 0.3s ease`, slight scale-up on active state.
* **Cards:** Soft `box-shadow: 0 4px 6px rgba(0,0,0,0.3)`.
