# 🐛 Troubleshooting & Debugging Guide
**Project:** EduBharat AI
**Environment:** Client-Side Single-File SPA (HTML/CSS/JS)

## 1. Overview
This guide provides resolution steps for common syntax, rendering, and DOM manipulation errors encountered when developing and editing single-file applications on mobile code editors.

## 2. Common Issues & Resolutions

### 2.1 Blank Screen on App Launch
* **Cause:** Unclosed `<script>` or `<style>` tags, or fatal JavaScript syntax errors (e.g., missing bracket or semicolon).
* **Fix:** Open browser DevTools (or Termux console) and inspect the `Console` tab. Look for `Uncaught SyntaxError` and check line numbers.

### 2.2 Role Switching Not Updating DOM
* **Cause:** ID mismatch between JavaScript `document.getElementById()` selectors and the HTML container `id` attributes.
* **Fix:** Ensure section IDs exactly match: `gateway-view`, `student-view`, `teacher-view`, `principal-view`, and `parent-view`.

### 2.3 Dark Mode Styling Broken on Mobile
* **Cause:** Missing viewport meta tag in the `<head>` block.
* **Fix:** Ensure `<meta name="viewport" content="width=device-width, initial-scale=1.0">` is present at the top of the HTML file.

### 2.4 Mock JSON Data Fails to Render
* **Cause:** Attempting to access undefined properties inside the mock data object (e.g., `mockDb.student.nonExistentKey`).
* **Fix:** Verify mock data keys in `4.DATABASE.md` against property names used in JavaScript template literals.
