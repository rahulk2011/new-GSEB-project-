# 🔌 API Specification & Mock Endpoints
**Project:** EduBharat AI
**Architecture:** Client-Side Mock REST Interface (v1.0 MVP)

## 1. Overview
EduBharat AI v1.0 operates entirely on client-side state without a live backend server. All API requests are simulated asynchronously in Vanilla JavaScript using `Promise` structures and `setTimeout` delays to mirror real-world network latency and behavior.

## 2. Base Configuration
* **Simulated Base URL:** `https://api.edubharat.local/v1`
* **Default Latency:** 800ms - 1500ms
* **Content Type:** `application/json`

## 3. Endpoints Specification

### 3.1 Authentication & Role Switching
* **Endpoint:** `POST /auth/switch-role`
* **Description:** Simulates session creation when switching roles on the Gateway screen.
* **Request Body:**
```json
{
  "role": "student",
  "userId": "STU-GSEB-1001"
}
```
* **Response (200 OK):**
```json
{
  "success": true,
  "token": "mock-jwt-token-role-student",
  "sessionExpiry": "2026-10-20T23:59:59Z"
}
```

### 3.2 Student Portal Endpoints
* **Endpoint:** `POST /student/ask-ai`
* **Description:** Sends student doubt to the simulated AI tutor engine.
* **Request Body:**
```json
{
  "studentId": "STU-GSEB-1001",
  "subject": "Science",
  "topic": "Chemical Reactions",
  "question": "What is an exothermic reaction?"
}
```
* **Response (200 OK):**
```json
{
  "status": "completed",
  "latency": "1450ms",
  "answer": "An exothermic reaction is a chemical reaction that releases energy by light or heat. Example: Combustion of natural gas."
}
```

### 3.3 Teacher Portal Endpoints
* **Endpoint:** `POST /teacher/attendance/submit`
* **Description:** Submits daily attendance status for assigned class.
* **Request Body:**
```json
{
  "classId": "10-A",
  "date": "2026-10-20",
  "records": [
    { "studentId": "STU-1001", "status": "present" },
    { "studentId": "STU-1002", "status": "absent" }
  ]
}
```
* **Response (200 OK):**
```json
{
  "status": "success",
  "message": "Attendance recorded for 45 students."
}
```

### 3.4 Principal Portal Endpoints
* **Endpoint:** `POST /principal/broadcast`
* **Description:** Dispatches emergency notices or circulars to chosen roles.
* **Request Body:**
```json
{
  "title": "Semester Exam Schedule",
  "targetRoles": ["teachers", "parents", "students"],
  "priority": "high",
  "message": "First semester examination commences next Monday."
}
```
* **Response (200 OK):**
```json
{
  "status": "dispatched",
  "recipientCount": 1502,
  "broadcastId": "BC-2026-88"
}
```
