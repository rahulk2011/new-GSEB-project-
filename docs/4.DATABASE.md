# 🗄️ Database Schema & Data Models
**Project:** EduBharat AI
**Architecture:** Client-Side Mock JSON Storage (v1.0 MVP)

## 1. Overview
For the v1.0 offline-first prototype, all persistence and dynamic views are managed through embedded Mock JSON objects within the JavaScript layer, removing server dependencies and infrastructure costs.
