# 📄 Product Requirements Document (PRD)
**Project:** EduBharat AI - Smart School OS
**Version:** 1.0 (MVP)
**Focus:** Gujarat Board (GSEB) Standard 10

## 1. Executive Summary
EduBharat AI is a multi-tenant Educational SaaS platform designed to bridge the communication and academic gap between Students, Teachers, Principals, and Parents. The v1.0 MVP is a lightweight, mobile-first Single-Page Application (SPA) utilizing AI-assisted development to demonstrate core value without heavy backend infrastructure.

## 2. Target Audience & Core Features

### 👨‍🎓 Student
* **Needs:** Quick revision, past papers, doubt solving.
* **Features:** 
  - AI Study Assistant (Mock integration)
  - Revision Note Vault (Dark-mode PDFs)
  - Gamified Progress Tracker

### 👨‍🏫 Teacher
* **Needs:** Class automation, quick evaluation.
* **Features:** 
  - Smart Attendance Toggle
  - AI Lesson Plan Generator UI
  - Evaluation Queue Dashboard

### 🏛️ Principal (Admin)
* **Needs:** Bird's-eye view, instant communication.
* **Features:** 
  - Real-time School Analytics (Total Students, Average Attendance)
  - Broadcast Notice System

### 👨‍👩‍👦 Parent
* **Needs:** Transparency and tracking.
* **Features:** 
  - Ward's Real-time Status (In-school/Absent)
  - Academic Progress Chart
  - Direct Teacher Messaging

## 3. User Stories
- **As a Student**, I want to click on 'AI Revision' so that I can quickly read standard 10 science notes on my mobile.
- **As a Teacher**, I want to toggle attendance with one click so that I save 15 minutes of manual register entry.
- **As a Principal**, I want to see the overall academic health score so that I can identify weak performing classes instantly.

## 4. Out of Scope for v1.0
- Live Video Classes
- Payment Gateway Integrations
- Actual Cloud Backend (Firebase) - *Planned for v2.0*
