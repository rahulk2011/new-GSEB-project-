# 🗺️ Feature Development & Roadmap Specifications
**Project:** EduBharat AI
**Lifecycle:** v1.0 MVP to v3.0 Production SaaS

## 1. Feature Lifecycle Overview
This roadmap tracks the feature progression of EduBharat AI across three deliberate phases, balancing rapid prototype delivery for academic validation with enterprise scalability for nationwide school deployment.

## 2. Feature Matrix: Current vs. Future Scope

| Feature Module | MVP (v1.0) - Current | Cloud Beta (v2.0) | Enterprise (v3.0) |
|---|---|---|---|
| **Architecture** | Monolithic Single-File SPA | Decoupled Client + Backend | Microservices & Edge CDN |
| **Data Persistence** | Client-side Mock JSON | Firebase Firestore / PostgreSQL | Distributed Multi-Region SQL |
| **Authentication** | Client State Toggle (Mock) | Firebase Auth (Email/Phone/SMS) | Biometric & State Board SSO |
| **AI Study Assistant** | Pre-computed Mock Dialogue | Live Gemini 1.5 Flash API | Fine-tuned GSEB Local LLM |
| **Attendance Engine** | Local State Checkbox Toggle | Cloud Sync with Daily Reports | Automated Computer Vision / RFID |
| **Grading Assistant** | Simulated Evaluation Delay | OCR Paper Upload + Rubric Scoring | Multi-language Handwriting AI |
| **Parental Tracking** | Static Bar Chart & Mock State | Real-time Push Notifications | Live Bus GPS & Geofencing |

## 3. Detailed Milestone Breakdown

### Milestone 1: Core Usability Validation (v1.0 MVP)
* Focus on frictionless mobile performance across low-end Android smartphones.
* High-contrast Dark Mode implementation to ensure accessibility during prolonged study sessions.
* Instant visual routing across 4 core roles (Student, Teacher, Principal, Parent).

### Milestone 2: Cloud Sync & Intelligence Integration (v2.0)
* Transition from in-memory state to persistent cloud storage via Google Firebase.
* Integration of official Gemini API keys for dynamic question generation and doubt resolution.
* Export engine allowing teachers to download PDF report cards and attendance sheets directly.

### Milestone 3: Ecosystem Expansion & Institutional Compliance (v3.0)
* Full compliance with GSEB examination regulations and state portal reporting standards.
* Multi-lingual UI toggle (Gujarati, Hindi, English).
* Automated grant and audit export reports for iHub / SSIP startup incubators.
