**EduBharat AI** is a comprehensive, mobile-first Educational SaaS platform designed to bridge the gap between Students, Teachers, Principals, and Parents. Initially architected for the Gujarat Board (GSEB) ecosystem, it aims to bring AI-powered tools and real-time analytics to every school.

---

## 🚀 Core Features (Role-Based Access)

*   **👨‍🎓 Student Portal:** AI Study Assistant, Quick Revision Notes, Past Board Papers, and Progress Tracking.
*   **👨‍🏫 Teacher Portal:** Smart Attendance System, AI Lesson Planner, and Pending Evaluation Queue.
*   **🏛️ Principal (Admin) Portal:** Real-time School Analytics, Staff Tracking, and Broadcast Notice System.
*   **👨‍👩‍👦 Parent Portal:** Live Student Status, Academic Progress Graphs, and Direct Teacher Messaging.

## 🛠️ Technical Stack & Development Methodology

*   **Architecture:** Monolithic Single-Page Application (SPA).
*   **Frontend:** Pure Vanilla HTML, CSS (Premium Dark Mode), and JavaScript. No external frameworks (Zero dependencies).
*   **Methodology (Smart Work):** Entirely engineered via **AI-Assisted Development (Prompt Engineering)** using Google AI Studio. Coded and deployed entirely from a mobile workspace using cloud terminals.

---

## 💻 How to Run Locally

Since the v1.0 MVP is a zero-dependency SPA, running it is incredibly simple:
1. Clone this repository to your local device.
2. Open the `index.html` file in any modern web browser (Chrome/Safari/Brave).
3. The platform is mobile-first, so switch your browser to "Responsive/Mobile View" for the best experience.
